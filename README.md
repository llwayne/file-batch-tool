# File Batch Tool 本地批量文件处理工具
MIT License | 纯Python标准库实现，无第三方依赖，本地离线处理文件，无隐私上传风险。

## 功能清单
1. 批量文件重命名：统一前缀、序号排序、删除多余字符
2. 文本批量替换：批量修改txt/md文件内指定关键词
3. 格式筛选：按后缀筛选文件（图片、文档、代码文件）
4. 批量移动/复制文件至指定文件夹

## 运行环境
Python 3.7+，仅内置os、json、shutil库，无需pip安装任何包。

## 快速使用
1. 将 `batch_file.py` 复制到需要处理文件的文件夹
2. 修改脚本顶部配置参数（目标文件夹、重命名规则、替换关键词）
3. 终端执行命令：
```bash
python batch_file.py
